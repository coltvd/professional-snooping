### Common Operators Quick Reference

| Operator | Example | What it does |
|----------|---------|--------------|
| `site:` | `site:linkedin.com "John Doe"` | Search within a specific domain |
| `filetype:` | `filetype:pdf "annual report"` | Find specific file types |
| `intitle:` | `intitle:"index of"` | Search page titles |
| `inurl:` | `inurl:admin` | Search within URLs |
| `"exact phrase"` | `"John Doe" "New York"` | Exact phrase match |
| `-keyword` | `apple -fruit` | Exclude a keyword |
| `*` | `"John * Doe"` | Wildcard |
| `OR` | `CEO OR founder` | Either term |
