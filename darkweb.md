# Dark Web

Resources for researching and navigating the dark web. Requires Tor Browser.

---

## Getting Started

| Tool | URL | Notes |
|------|-----|-------|
| Tor Project | [torproject.org](https://www.torproject.org) | Download Tor Browser — required to access .onion sites |

> Always use Tor Browser on a dedicated VM (see [Operational Security](operational-security.md)). Never access .onion sites from your regular browser or personal machine.

---

## Search Engines

| Tool | URL | Notes |
|------|-----|-------|
| Ahmia | [ahmia.fi](https://ahmia.fi) | Clearnet-accessible Tor search engine; indexes .onion sites |
| Torch | Available via Tor | One of the oldest Tor search engines |
| Onion Search Engine | onionsearchengine.com | Search .onion directories |

## Operational Notes

- Never log into personal accounts while on Tor
- Disable JavaScript in Tor Browser for higher anonymity
- Do not download files via Tor unless in an isolated VM
- Treat all .onion links as unverified — directories go stale quickly
