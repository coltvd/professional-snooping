# Investigation Workflow

A checklist and template for setting up and scoping an investigation before any research begins.

---

## Pre-Investigation Checklist

Before starting, document the following in writing:

| Item | Notes |
|------|-------|
| Task / Objective | What are you trying to find or prove? |
| Contact Info | Client name, phone, email, preferred contact method |
| Scope of Work | What is included |
| Out of Scope | What is explicitly excluded |
| Special Considerations | Sensitivities, legal constraints, jurisdiction |
| Timeline | Start date, milestones, deadline |
| Data Retention | Encrypted storage? File shred after delivery? |
| Delivery Format | Email, letter, secure drop, in-person |

---

## Deliverables

- All findings should be delivered **in writing** (email or letter) unless agreed otherwise
- Use **cherry tree templates** for structured case documentation
